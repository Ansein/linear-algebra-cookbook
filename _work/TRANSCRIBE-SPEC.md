# 转录规范（LaTeX 片段编写手册）

> 本文件会被 `init_project.py` 拷贝到 `<项目>/_work/TRANSCRIBE-SPEC.md`。
> 每个子代理开工前必须先读它。
> 最终排版样式已由 `_work/style.tex` 固定，你只写"正文片段"，
> 禁止修改样式、禁止使用未列出的宏包。

---

## 1. 硬性规则

1. 严禁增删内容：原稿有什么就写什么，不补充、不删减、不合并、不"优化"、不加自己的评注。
   原稿的笔误、错别字、编号跳号、错乱标点一律照抄——只在最终回复里报告，不要擅自"改正"。
2. 公式必须用 LaTeX 数学环境精确重现，不要用图片、不要用文字描述公式。
3. 只允许使用第 2 节列出的宏和环境（外加 `amsmath` 标准环境与 `\text{}`）。
4. 不要写 `\documentclass` / `\usepackage` / `\begin{document}`，你写的是片段。
5. 中文直接用汉字；下标/上标里的中文用 `\text{...}`，例如 `A_{\text{余子式}}`。
6. 微分算子用 `\mathrm{d}`：`\int_a^b f(x)\,\mathrm{d}x`。
7. 向量 `\vec{a}`；矩阵 `\begin{pmatrix}`；行列式 `\begin{vmatrix}`。
8. 分段函数 `\begin{cases}`；多行对齐 `\begin{aligned}` 或 `align*`。
9. 保持原稿编号文字不变（"七、次方公式"→`\fsec{七、次方公式}`；"1.行列式"→`\fcard{1. 行列式}`）。
10. 写完就检查花括号、`\left`/`\right`、环境首尾是否配对。

## 2. 可用宏与环境（唯一接口）

| 宏 / 环境 | 用途 | 示例 |
|---|---|---|
| `\fchap{...}` | 章/部分标题（深色大号带） | `\fchap{第三章\quad 一元函数积分学}` |
| `\fsec{...}` | 节标题（浅色带） | `\fsec{一、行列式、伴随、逆的公式}` |
| `\fcard{标题}` … `\end{fcard}` | 普通公式卡片（最常用） | 见下 |
| `\fkey{标题}` … `\end{fkey}` | 强调卡片（口诀、必记结论、重点） | `\begin{fkey}{必记结论}` |
| `\begin{fnote}` … `\end{fnote}` | 提示框（注意/说明、原稿括号里的注解） | `\begin{fnote}注意：...\end{fnote}` |
| `\begin{fdeep}{标题}` … `\end{fdeep}` | 【深化】灰底拓展框——本项目专用，只用于高等代数深化内容 | `\begin{fdeep}{多重线性视角}` |
| `\fgroup{...}` | 小组标签（原稿的【第一组】等） | `\fgroup{【第一组】}` |
| `\fml{公式}` | 居中显示公式（卡片内一行公式，首选） | `\fml{\|kA\|=k^{n}\|A\|}` |
| `\fmll{公式}` | 左对齐显示公式（长式子、需断行） | `\fmll{a^{n}-b^{n}=(a-b)(\cdots)}` |
| `\figimg[宽]{文件名}` | 插入已裁好的原稿位图 | `\figimg[3.1cm]{surf_sphere}` |
| `\iddots` | 反向省略号（副对角线方向）——必须用它，不要用 `\ddots` 顶替 | `\begin{bmatrix} & & a\\ & \iddots & \\ b & & \end{bmatrix}` |
| TikZ 宏 | 已重绘的图像，见 `tikz-library.tex` | `\figarcsin` `\figcycloid` `\figastroid` `\figcardioid` `\figlemniscate` |

> `\ddots` 与 `\iddots` 的分工（很容易搞错，且错了在数学上是错的）：
> - `\ddots` 是主对角线方向的三个点，用于 $a_{11},a_{22},\dots,a_{nn}$ 这类位置；
> - `\iddots` 是副对角线方向的三个点，用于 $a_{1n},\dots,a_{n1}$ 这类位置
>   （如副对角线分块矩阵 $\begin{bmatrix} & & A_1\\ & \iddots & \\ A_s & & \end{bmatrix}$）。
> `\iddots` 已在本仓库 `style.tex` 中定义好，直接使用即可。

卡片内也可直接写 `\[ ... \]`（等价 `\fml`）。

### 关于 `fdeep`（本项目特有，务必分清）

本项目是「考研蓝本」，不是原书全量重排。因此：

- 《线性代数9讲》的页面：知识正文 + 例题全部转写，用 `fcard` / `fkey` / `fnote`。
- 北大《高等代数》与樊启斌《高等代数典型问题与方法》的页面：这些是深化材料。
  只转写概念、定理、性质、关键证明思路，跳过：例题解答、习题、与考纲无关的纯理论、
  历史注记。转写出来的内容一律包在 `fdeep` 里，标题写知识点名。
- `fdeep` 里可以正常使用 `\fml`、`\fmll`、`\[...\]` 与 `amsmath` 环境。
- 若某页整页都是例题或习题，就不要勉强转写，在 `%` 注释里说明
  （如 `% beida p58 全部为习题，按规范跳过`）即可，并在最终回复里报告。


### 标准骨架

```latex
\fchap{第一章\quad 函数、极限与连续}
\fsec{一、常用不等式}
\begin{fcard}{1. 基本不等式}
\fml{\ln x\le x-1\qquad (x>0)}
\fml{\frac{x}{1+x}<\ln(1+x)<x<e^{x}\qquad (x>0)}
\end{fcard}

\begin{fnote}
注意：这里说的是 $x>0$ 的情形。
\end{fnote}

\fgroup{【第一组】}
\begin{fcard}{2. 次方公式}
\fml{a^{3}+b^{3}=(a+b)(a^{2}+b^{2}-ab)}
\end{fcard}

\begin{fkey}{必记结论}
\fml{A^{*}=|A|A^{-1},\qquad |A^{*}|=|A|^{n-1}}
\end{fkey}
```

### 怎么选卡片类型

- 原稿用方框/表格框起来的独立编号条目 → `fcard`，标题写原编号与名称。
- 原稿标了口诀/结论/必记/重点，或明显是"背下来"的 → `fkey`。
- 原稿括号中的补充说明、小字注解 → `fnote`。
- 原稿【第一组】【第二组】 → `\fgroup{【第一组】}`。
- 原稿页面顶部的章、节标题 → `\fchap` / `\fsec`（按原文层级，不要自己改）。

### 版式转换约定（原稿是表格时）

原稿常把若干编号条目左右并排放在一个表格里。此时：

- 每个编号条目各写成一张 `fcard`，标题用原编号与名称。
- 输出顺序按原编号数字顺序（1、2、3、4…），不要按左右位置跳序。
- 同一格内的多行公式全部放进同一张卡片。
- 多列表格无法在单栏宽度并排时，同一张卡内先左栏再右栏，保持栏内顺序不变。

## 3. 页面类型处理

- 封面页：不要排版，用注释记录：`% COVER: <封面上的所有文字>`
- 目录页：不要排成表格，用注释块记录条目：
  ```
  % TOC-ENTRIES-BEGIN
  % 第一章 函数、极限与连续
  % 一、函数的概念
  % TOC-ENTRIES-END
  ```
  （目录由主控自动生成，你只提供条目文字）
- 正文页：全部转写，包括页面顶部的章节标题；页眉页脚忽略（那是每页重复的装饰）。

## 5. 自检（必须做）

```bash
cd "<项目>/_work"
cat > _chk_<你的片段名>.tex <<'EOF'
\documentclass[11pt]{ctexart}
\input{style.tex}
\input{tikz-library.tex}
\begin{document}
\input{frag/<你的片段名>.tex}
\end{document}
EOF
xelatex -interaction=nonstopmode _chk_<你的片段名>.tex > _chk_<你的片段名>.log 2>&1
echo "exit=$?"
grep -n "^!" _chk_<你的片段名>.log | head -20
grep -c "Missing character" _chk_<你的片段名>.log
```

要求：`exit=0`、`grep "^!"` 无输出、缺字计数为 0。
`Overfull \hbox` 警告可忽略，由主控统一处理。
完成后删除 `_chk_*` 文件（保留片段 `.tex`）。
